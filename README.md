### The Business Problem
61% of luxury retail clients in the Middle East 
purchase from only one category — despite multi-category 
clients showing 2.5x higher lifetime value.

### Key Insight
Even within the VIP segment, 19.7% of clients have 
never explored a second category. These represent the 
highest-value cross-category opportunity in the portfolio.

### What This Dashboard Surfaces
- Entry category distribution for single-category clients
- Natural migration paths between categories
- Single-category behaviour by client tier
- Priority action list: highest-value clients + recommended 
  next category + months since last visit

### Note on Data
Built on simulated data mirroring luxury retail CRM 
structures. The analytical logic applies directly to 
live client data.
